DATA AVAILABILITY STATEMENT

Manuscript Title: ConCGR-AoI: Distribution-Free Conformal Contact-Graph Routing and Age-of-Information Control for Disrupted Flying Ad-Hoc Networks
Author: Vishal Chandel
Affiliation: Department of Electronics and Communication Engineering, Jawaharlal Nehru Government Engineering College Sundernagar, Himachal Pradesh, India

Data Availability:
The complete set of empirical data, simulation scripts, and hardware testbed packages supporting the findings of this study are preserved and available:

1. Topographical & Elevation Data:
   The NASA Shuttle Radar Topography Mission (SRTM) 30-meter Digital Elevation Model for the Kangra Valley, Himachal Pradesh, India (161 x 162 grid, elevation 1,240 m - 2,344 m ASL) is publicly accessible via the USGS EarthExplorer portal (https://earthexplorer.usgs.gov) and provided as raw elevation arrays in the repository.

2. Atmospheric & Wind Field Telemetry:
   Non-stationary atmospheric wind velocity and gust time series were acquired from the Open-Meteo High-Resolution Mountain Weather Archive for the Kangra Ridge coordinates (32.1°N, 76.2°E).

3. Authentic Multi-Modal Sensor Payloads:
   - Thermal Infrared: Authentic FLIR TAU-2 Long-Wave Infrared (LWIR) radiometric frames (640x512 resolution, 14-bit thermal radiance) capturing active wildfire fronts.
   - 3D LiDAR Submaps: Point Cloud Data (PCD) UTM submaps acquired by airborne UAV LiDAR scanners.
   - Quadrotor Flight Dynamics: Real 50 Hz PX4 Autopilot v1.14 cascaded PID attitude and altitude telemetry logs under mountain wind shear disturbances.

4. Source Code and Simulation Artifacts:
   - C++17 Core Engine (concgr_core): Standalone library implementing Online ACI calibration, Quota Limiter, and Minimax AoI Dijkstra routing.
   - Discrete-Event Simulation Stack: ns-3.40 integration scripts enforcing IEEE 802.11p OCB PHY/MAC CSMA/CA contention, knife-edge diffraction, and 117 benchmark missions.
   - Hardware-in-the-Loop Testbed: ROS 2 Humble Hawksbill packages (concgr_dtn_bridge) implementing RFC 9171 BPv7 frames and microsecond packet pacing.

All relevant source code, configuration files, and benchmark trajectory logs will be hosted on an open-access GitHub / Zenodo repository upon publication.
